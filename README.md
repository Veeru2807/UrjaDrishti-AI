## 💡 What is UrjaDrishti AI? (Easy Explanation)

**UrjaDrishti AI** is an AI-powered smart building energy intelligence and optimization SaaS platform designed for facility managers, building owners, CEOs, and energy auditors.

Instead of just showing raw numbers, **UrjaDrishti AI** converts sub-meter data into **six simple business answers**:

1. **How much energy are we using?** — Track real-time power demand (kW) and cumulative daily energy (kWh).
2. **Where are we wasting energy?** — Identify specific floors and zones over-cooling empty rooms or running lights after hours.
3. **Why is energy consumption changing?** — Correlate power spikes with weather conditions, occupancy levels, and HVAC setpoints.
4. **What will happen next?** — 24-hour predictive load forecasting and DISCOM peak time-of-day (TOD) warnings.
5. **What action should we take?** — Get automated AI recommendations ranked by financial impact and comfort protection.
6. **How much can we save?** — Model interactive What-If scenario simulations and calculate ROI for BEE/ECBC retrofits.

## ✨ Key Features & Highlights

### 📊 1. 10-Tab Intelligence Dashboard
- **Executive Overview:** High-level CEO metrics, daily kWh, cost (₹), energy intensity (EPI), peak demand, and comfort score.
- **Energy Analytics & Disaggregation:** Load breakdown (HVAC, Lighting, Equipment), baseline comparison, and 7-day/30-day historical trends.
- **Floor & Zone Micro-Climate:** Floor-by-floor sub-metering, VAV state inspection, and occupancy-linked anomaly detection.
- **Indoor Comfort Intelligence:** ASHRAE 55 & NBC India thermal comfort compliance, relative humidity, and CO₂ safety index.
- **AI Action Center:** Automated anomaly root-cause analysis with 1-click optimization commands.
- **Peak Demand & Grid Response (TOD):** DISCOM peak tariff mitigation and flexible load shifting simulator.
- **What-If Scenario Simulator:** Interactively adjust setpoints, solar capacity, operating hours, and pre-cooling schedules to predict savings.
- **Retrofit & Conservation Advisor:** Capital expenditure (CapEx) payback calculation for LED upgrades, VFD installation, and solar rooftop integration.
- **BMS & IoT Integration:** BACnet/Modbus data pipeline architecture and DISCOM Automated Demand Response (ADR) readiness.
- **Executive Reports:** Audit-ready compliance reports, ESG summaries, and exportable PDF/CSV energy audits.

### 🔒 2. Dynamic OTP Authentication System
- **6-Digit Dynamic OTP:** Generates cryptographically unique verification codes on demand.
- **Interactive SMS Gateway Toast:** Real-time floating SMS notification card with a 1-click **Auto-Fill** button.
- **Phone Registration Flow:** Unregistered mobile numbers complete a quick registration form (Full Name, Work Email, Company, Role) before accessing workspace setup.
- **Security Protections:** 60-second resend countdown timer, 5-minute TTL expiry, and 5-attempt rate limiting lock.

### 🏢 3. Dynamic Building Engine & Multi-Building Persistence
- **100% Dynamic Math Engine:** Daily kWh, cost (₹), peak kW, and energy intensity compute in real-time based on building area (m²), floors count, electricity tariff (₹/kWh), climate zone, and occupancy.
- **Saved Facilities Dropdown:** Onboard multiple custom buildings. All added facilities remain saved in `localStorage` with seamless 1-click switching to Demo Office.

### 👤 4. User Profile System
- Profile modal displaying account details, role certifications (BEE/ECBC), verified phone number, active session token, and 1-click **Sign Out** from any page.

## 💻 Local Installation & Setup

To run **UrjaDrishti AI** locally on your computer:

```bash
# 1. Clone the repository
git clone https://github.com/Veeru2807/UrjaDrishti-AI.git

# 2. Navigate into the project directory
cd UrjaDrishti-AI

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open your browser and navigate to `http://localhost:5173/`!
